# GBF TOOLBOX

グランブルーファンタジーのプレイ記録・計算をまとめる、非公式のAndroid補助ツールです。

## 機能
- 周回ログ・ドロップ記録（アーカーシャ／つよバハ等）
- ドロップ率・平均周回数の集計
- 編成・攻略メモ
- 素材目標と所持数の管理
- 日課チェック
- 端末内保存、JSONバックアップ／復元

ゲーム本体への接続、通信解析、自動操作は行いません。

## Build
GitHub Actions の「Build Android APK」から実行できます。生成物は workflow artifact の `GBF-TOOLBOX-debug-apk` です。
